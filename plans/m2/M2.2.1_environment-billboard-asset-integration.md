## Objective

Replace the M2.2 primitive foliage billboards in the maintained production `BattleLab` presentation with the seven committed source sprites under `assets/environment/m2/foliage/`, while preserving all accepted M2.2 terrain/scatter/projection/camera behaviour and all M1 authority identities.

## Context

- The seven 512×512 transparent RGBA sources are `grass_clump_01.png`, `grass_clump_02.png`, `shrub_leafy_01.png`, `shrub_scrub_01.png`, `tree_small_01.png`, `tree_small_02.png`, and `dead_brush_01.png`. Their intended categories are documented in `assets/environment/m2/foliage/README.md`.
- `BattlefieldFoliageScatter` is the immutable placement authority for this pass. Its ordered positions, `Kind`, scale/tint/flip fields, exclusions, count, and canonical scatter digest must remain unchanged. The visual presenter may select a source sprite deterministically from existing placement identity/category fields only.
- Terrain-relative placement remains one-way through `BattlefieldPresentationProjector` and the M2.1 sampler. Foliage is non-colliding presentation only.

## Required Behaviour

1. Retire the primitive Side A/Side B placeholder textures from foliage presentation and use all seven committed foliage images through the smallest Godot-native mechanism compatible with the existing `BattlefieldTerrainView` path. Direct `Texture2D` loading is acceptable; source-controlled `.tres` resources are permitted only if they make this current path simpler.
2. Keep visual mapping centralized in the foliage presentation path. Mapping must be deterministic: the same existing placement produces the same source asset on repeat, without Godot/global/system/random runtime selection.
3. Make each of the seven committed sources reachable by the chosen mapping where appropriate. Preserve `Tree`, `Bush`, and `Rock` placement identity/categories; rocks remain the existing simple props unless a visual selection from the source family is appropriate without changing placement data.
4. Calibrate authored sources in actual production BattleLab. Preserve a readable hierarchy: grass low; shrubs and dead brush medium; small trees tallest. Compensate for source transparent padding using normal presentation pixel size, node scale, and/or vertical offsets; do not alter PNG pixels.
5. Verify Godot import and actual Forward+ rendering: alpha is transparent with no opaque backgrounds or obvious coloured/white halos; silhouettes are not excessively blurry; foliage billboards face the camera, remain terrain-grounded while pan/zooming, do not severely pop, obscure formations, or interfere with HUD/input.
6. Keep existing runtime evidence/report scope stable unless a minimal integration check is genuinely needed. The deterministic proof remains the placement/scatter data, not reporting the GPU-selected image for every node.
